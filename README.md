# Task-manager-fullstack-springboot-react-app
Full-stack application using Spring Boot (REST API) and React (frontend) demonstrating API integration.

# Spring Boot + React Integration Project

## Overview

This project is a full-stack application demonstrating integration between a Spring Boot backend and a React frontend.

* Spring Boot provides REST APIs
* React consumes APIs and renders UI

---

## Tech Stack

* Backend: Spring Boot, Java
* Frontend: React.js
* Communication: REST API (JSON)

---

## Project Structure

/backend → Spring Boot application
/frontend → React application

---

## Features

* REST API built with Spring Boot
* React frontend with API integration
* Fetching and displaying backend data
* Basic CORS configuration

---

## Getting Started

###  Clone Repository

git clone https://github.com/your-username/your-repo-name.git

---

### 2. Run Backend

cd backend
./mvnw spring-boot:run

Runs on: http://localhost:8080

---

### 3. Run Frontend

cd frontend
npm install
npm start

Runs on: http://localhost:5173/

---

## API Endpoints

### GET /api/hello

Returns a simple string response.

### GET /api/user

Returns sample JSON data.
